# Remotion Captioning

Use this reference when the user mentions Remotion or wants motion captions, CTA cards, product overlays, or repeatable video assembly.

## When To Use Remotion

Use Remotion when the ad needs:

- Repeatable timed caption templates.
- Product overlays and end cards.
- Brand typography.
- Motion graphics.
- Variant rendering at scale.
- Cleaner handoff than a one-off editor timeline.

## Composition Defaults

- Width: 720 or 1080.
- Height: 1280 or 1920.
- FPS: 24 or 30.
- Safe areas: leave top and bottom room for TikTok UI.
- Audio: import approved VO, BGM, and SFX as separate layers.

## Caption Rules

- One short thought per caption.
- Keep captions within safe area.
- Use high contrast.
- Do not cover the product, face, hands, or CTA.
- Keep claim wording identical to source-backed approved copy.

## End Card Rules

- Use exact product image or approved packshot.
- Add brand/product name in a text layer.
- Add CTA in a text layer.
- Add price or offer only after advertiser confirmation.
- Add legal note only when required and keep it readable.

## Handoff Fields

For a Remotion handoff, provide:

- Video segment file paths.
- Audio file paths.
- Timed captions.
- Product image path.
- End card copy.
- Brand colors and font choices.
- Export settings.
