# Delivery Checklist

Use this checklist before final handoff.

## Strategy Package

- Product summary.
- Audience summary.
- Offer summary.
- Claim boundaries.
- Angle matrix.
- Hook set.
- Testing priority.

## Editor Handoff Package

- Storyboard.
- Voiceover copy.
- On-screen copy.
- AI prompt pack if relevant.
- Editing brief.
- Asset list.
- Missing asset list.

Use this package when the user asks for prompts, files, or handoff to an editor. If the user asked the agent to make, generate, render, or create a video, do not stop here after creative approval; continue into tool selection and finished video production.

## Rendered Video Production

- Confirmed creative draft.
- Chosen image/video tools or models.
- Chosen voiceover, BGM, and SFX tools or models.
- Chosen assembly/rendering tool.
- Generated visual segments.
- Generated or selected audio assets.
- Captions and overlays.
- Assembled video file.
- QC notes and any regeneration list.

## QC Package

- Claim review.
- Visual risk review.
- TikTok fit score.
- Required fixes.
- Launch recommendation.

## File Naming

Use clear names:

- creative-brief.md
- angle-matrix.md
- hooks.md
- storyboard-30s.md
- prompt-pack.md
- editing-brief.md
- qc-scorecard.md
- launch-test-plan.md

## Final Response Shape

When handing off in chat, keep it scan-friendly:

1. Short summary.
2. Recommended angle.
3. Hook options.
4. Storyboard.
5. Editing notes.
6. QC risks.
7. Next test plan.

For a production request, the creative-draft response must end with:

1. Confirmation question.
2. Clear statement that approval starts finished video production.
3. Tool/model selection prompt for image/video, voiceover, BGM/SFX, and assembly.
