# Iteration Loop

Use this reference to improve a full ad package or generated asset set.

## First Pass

Create a complete package before judging tiny details:

- Source ledger.
- Creative brief.
- Angle matrix.
- Hook set.
- Storyboard.
- Prompt pack.
- Editing brief.
- QC scorecard.

## Review Pass

Score the package against:

- Product fact accuracy.
- First 3 seconds.
- Visual proof strength.
- TikTok native feel.
- Product visibility.
- Mobile readability.
- Claim safety.
- Distinctness between variants.
- Ease of production.

## Revision Pass

Improve:

- Hook specificity.
- Visual action.
- Product exposure.
- Proof clarity.
- CTA clarity.
- Risky language.
- Segment prompts.
- Editing notes.
- Screen handling for phones, laptops, tablets, watches, dashboards, and app surfaces.

## Stop Conditions

Stop when:

- The package has a clear recommended angle.
- Each beat maps to a source-backed product fact or safe audience insight.
- Generated media prompts are executable.
- QC risks are explicit.
- Remaining gaps require advertiser confirmation or tool access.

## Generated Media Learning

When an asset fails, record:

- Asset name.
- Prompt used.
- Model used.
- Failure type.
- Revised prompt rule.
- Whether the failed asset should be deleted, kept as a learning artifact, or excluded from final delivery.
